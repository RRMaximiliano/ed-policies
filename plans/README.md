## Findings considered and rejected

- **useSearch dependency-array "double rebuild"** (`src/hooks/useSearch.ts:32`): `policies`
  in the inner memo deps is required for the empty-query return value; cost at n=65 is
  negligible. Not worth doing.
- **Zustand persist hydration guard** (`src/store/filterStore.ts:104`): static export is
  client-rendered under Suspense; `persist` handles rehydration. No observed mismatch.
- **Label-lookup helper hooks**: `COUNTRY_LABELS[x]` inline lookups are idiomatic and O(1);
  a hook adds indirection for zero gain.
- **CommandPalette should use Fuse**: cmdk ships its own ranking filter; replacing it with
  Fuse changes UX for marginal benefit. Revisit only if users report misses.
- **Next.js minor bump for npm-audit CVEs**: nearly all flagged CVEs target server
  features (middleware, rewrites, image optimization) unused in this `output: 'export'`
  site. Recommend routine dependency updates via Dependabot rather than a plan here.
- **Ship policies.json outside the JS bundle**: real at scale, but at 65 policies the
  gzipped cost is small and per-policy static pages (plan 004) remove the need to open
  the SPA for deep links. Revisit past ~200 policies.
- **useUrlSync back/forward race** (`src/hooks/useUrlSync.ts:37-73`): MED-confidence smell
  only; needs a reproduction before it earns a fix plan.
